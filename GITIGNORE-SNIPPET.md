# Gitignore snippet

Use this if you want to keep the safe contribution workflow local and not commit it.

Add this to your `.gitignore`:

```gitignore
# Local safe contribution workflow
safe-contribution/
```

Use this when:

- You are contributing to someone else's repository.
- You do not want to modify the repository structure.
- The workflow is only for your personal use.
- You want to keep task-specific instructions local.

Do not add this if your team wants to commit and share the workflow.
